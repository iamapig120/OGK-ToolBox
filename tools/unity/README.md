# Unity type database

`classdata.tpk` is taken from the official UABEA v8 Windows release and is used only by the
read-only development/test path that extracts named `Texture2D` objects from Unity serialized
asset files. It is not included in the OGKToolBox publish output.

- Project: https://github.com/nesrak1/UABEA
- Upstream release: https://github.com/nesrak1/UABEA/releases/tag/v8
- AssetsTools.NET: https://github.com/nesrak1/AssetsTools.NET

The extracted ONGEKI chart images and sounds in `src/OGKToolBox.App/Assets/chart` originate from
the local game installation supplied by the project owner and are bundled at their explicit request.
