# Product

## Register

product

## Users

ONGEKI cabinet owners, controller builders, chart authors, and technically capable players working on a Windows machine next to a local game installation. Their primary job is to understand, verify, preview, and eventually package game resources without risking the running installation.

## Product Purpose

OGKToolBox turns the game's scattered A000 and Option resources into a trustworthy, searchable library. Success means users can identify which resource is active, inspect music and chart metadata, preview media, export selected material, and diagnose broken packages without editing the source installation.

## Brand Personality

Precise, composed, energetic. It should feel like a professional media workstation with a restrained arcade pulse.

## Anti-references

- Not a neon gaming dashboard with permanent glow and low-density panels.
- Not a generic Windows settings clone with no identity.
- Not a grid of decorative cards hiding the underlying data.
- Not a glassmorphic or gradient-heavy concept interface.

## Design Principles

1. Put the resource and its provenance before decoration.
2. Make large libraries fast to scan and predictable to filter.
3. Keep every game-directory operation visibly read-only.
4. Use ONGEKI color as state and navigation, never ambient noise.
5. Preserve unknown source data instead of silently normalizing it away.

## Accessibility & Inclusion

Target WCAG AA contrast, full keyboard navigation, visible focus states, scalable layout at 100–150% DPI, redundant non-color status cues, and respect for the Windows reduced-motion and high-contrast settings.
